OriginatingRequestId
Marker in an outbound request’s non-serialized Extensions identifying the in-flight peer request it was issued from (SEP-2260). Attached for both roles whenever a request is sent from within a request handler; the streamable HTTP server reads it to deliver server-initiated requests on the originating request’s SSE stream. Never on the wire (SEP-2260 defines no wire field), so session managers that serialize messages between processes lose it and such requests fall back to the standalone stream with a warning.
