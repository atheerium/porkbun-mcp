Source

pub fn strip_result_type_for_legacy_peer(&mut self)

Strip the SEP-2322 resultType: "complete" discriminator so the result keeps the wire shape that predates protocol version 2026-07-28.

The server handler calls this before responding to a peer that negotiated an older protocol version, where the field did not exist and strict peers may reject it. Only the "complete" value is stripped: results whose discriminator carries meaning ("input_required", "task") are already gated to 2026-07-28+ sessions, and custom extension values are preserved.

§Examples
use rmcp::model::{CallToolResult, ServerResult};

let mut result = ServerResult::CallToolResult(CallToolResult::success(vec![]));
result.strip_result_type_for_legacy_peer();

let json = serde_json::to_value(&result).unwrap();
assert!(json.get("resultType").is_none());
